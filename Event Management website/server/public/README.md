Place your Codesky logo image here as `logo.png` if you prefer a server-local copy.

Usage:
- Server-side PDF generation will look for `server/public/logo.png`.
- If not present, the generator will also search `client/public/logo.png` and `client/images/codesky.png`.

If you have `codesky.png` in `client/images/`, the server will use that image automatically.

Recommended formats: PNG or SVG. Recommended max width: 800px.
